PromptMiser

貼上一段 prompt，即可看到它的 token 數與在多個模型上的預估花費，並可一鍵將冗詞與重複指令壓縮。

角色：獨立開發技術主軸：成本分析 · 前端計算平台：網頁（PWA）
GitHubLive Demo

重點

+

即時成本試算

貼上 prompt 後即時顯示 token 數與各模型的預估費用，輸入變動時同步更新。

token 計算完全在瀏覽器端以 js-tiktoken 執行，不呼叫任何付費 API，因此能即時反應，也不會因為反覆試算而產生費用。

+

模型比價

一次比較多家供應商、數十個模型的價格，可切換每次 / 每 token，並對照訂閱方案。

同一段 prompt 在各家的單價差異一併列出，也可對照 Claude Pro、ChatGPT Plus 等訂閱方案的費用，判斷走訂閱或 API 較划算。

+

一鍵壓縮

刪去冗詞、合併重複指令、精簡範例，並呈現壓縮率與省下的金額。

壓縮後與原文逐段比對，刪去的部分標示為紅色、保留的內容維持原樣，使刪改範圍清楚可見。

+

省錢建議

依任務類型提供換模型、開啟快取、調整格式等策略，並附上預估省額。

除了比價，亦評估各模型對該任務的適用性，將建議整理為可實際執行的動作。

為什麼做這個

我越來越常使用各種 AI 模型，卻不太清楚用量為什麼有時候消耗得特別快——同一段內容，換個寫法或換個模型，費用就差了不少，卻很難看出差在哪，也不知道能從哪裡著手節省。

後來也常看到有人在意同樣的事。使用 AI 的人會討論哪個模型比較划算、值不值得為了成本更換方案；對公司或團隊而言，token 成本更是直接列入預算的項目——一段不必要的長 prompt，乘上每天數萬至數十萬次的呼叫，就是一筆可觀的支出，並會隨使用量整體放大。既然成本是普遍在意的問題，卻缺少一個能貼上 prompt 就同時看到花費、壓縮空間與省錢方式的工具，於是我做了 PromptMiser。

功能總覽

📊 成本一覽與排序+並排列表，可排序、切換單位

將同一段 prompt 在各模型的費用並排為表格，可依價格排序、切換「每次請求 / 每 token」兩種檢視，方便比較各家的價差。

🧾 對照訂閱方案+判斷訂閱或 API 較划算

單看單價較難有實感，因此另外對照 Claude Pro、ChatGPT Plus 等訂閱方案的費用，作為選擇訂閱或 API 的參考。

✂️ 壓縮、比對、複製+確認刪改後再套用

壓縮結果與原文逐段比對，標示刪去與保留的內容，並附上壓縮率與省下的金額；確認語意無誤後可一鍵複製精簡版。

🧭 省錢建議清單+每項標示預估省額

依任務類型列出換模型、開啟快取、調整輸出格式等策略，每一項均標示預估可省下的金額，作為調整的依據。

關鍵技術決策

將 token 計算移至瀏覽器端

token 數是最頻繁重算的資訊，使用者每次輸入都希望立即看到最新成本。若每次都經由後端或付費 API，不僅有延遲，也會為了試算本身持續產生費用。因此改以 js-tiktoken 在瀏覽器端計算，輸入變動即時更新，無延遲、亦無 API 費用；後端僅在壓縮與建議等需要進一步處理的環節介入。

系統架構

手機 / 電腦瀏覽器（PWA）
├── 前端即時計算
│ └── js-tiktoken：token 數與費用（不產生 API 費用）
↓ HTTPS（同源）
Vercel（同一專案部署）
├── 靜態 SPA：Vue 3 前端
└── Serverless Function：Python FastAPI 後端
├── 壓縮：改寫後與原文比對差異
└── 建議：判斷任務類型 → 產生省錢策略
