桌面工具

ClaudeQuota

給 Claude Pro / Max 使用者的 Windows 系統匣小工具：隨時顯示 5 小時與每週用量，以及各自什麼時候重置。數字只取官方來源，取不到就直說，不做推估。

角色：獨立開發、開源發佈技術主軸：桌面 UI · 系統整合平台：Windows 10 / 11（單一 exe）
GitHubLive Demo

重點

+

只用官方數字

讀官方用量端點，失敗改讀桌面版本機快取

約每 2 分鐘向官方用量端點取一次；取不到時改讀 Claude 桌面版的本機快取；兩者都沒有就明確顯示讀不到，不自己估算。

+

三種顯示方式

系統匣圖示、置頂卡片、工作列迷你橫條

圖示有 6 種樣式、顏色隨用量變紅；卡片顯示兩種額度與重置時間；也能縮成橫條貼在工作列上，各自記住位置。

+

不擋路

Win+D、切換虛擬桌面都不會消失，全螢幕自動讓開

卡片在顯示桌面與切換虛擬桌面時維持在原位；偵測到全螢幕遊戲或影片時自動隱藏，結束後再回來。

+

CI 建置發佈

exe 由 GitHub Actions 建置並附 SHA-256

每個版本的 exe 都由 GitHub Actions 從原始碼建置，附上校驗碼，使用者不需要安裝 Python。

為什麼做這個

我每天都在用 Claude Code，最常遇到的狀況是做到一半突然被告知「已達用量上限」，而且不知道還要等多久才會重置。官方雖然有用量頁面，但要特地打開才看得到。

所以想要一個不用打開任何東西、瞄一眼工作列就知道還剩多少額度的小工具，順便練習 Windows 桌面程式在多螢幕、虛擬桌面、全螢幕等情境下的行為處理。

功能總覽

📊 用量卡片+兩種額度、進度條、重置時間

顯示 5 小時與每週額度的用量與進度條，以及剩多久重置、確切的重置時間（每週額度會標星期幾）。

🎨 系統匣圖示+6 種樣式，快用完時變紅

星芒、已用數字、剩餘數字、進度環、圓餅、雙條六種樣式，在淺色與深色工作列上都清楚；滑鼠停留可看摘要。

⚡ 手動起算 5 小時視窗+一鍵送出極小請求開始計時

可以提早開始 5 小時視窗；另有預設關閉的「重置後自動起算」，開啟前會說明每次約花掉 1–2% 的額度。

🌐 中英文介面+跟隨 Windows 語言

介面依 Windows 語言自動切換中英文，也可以從系統匣選單手動切換；選單內建使用說明。

關鍵技術決策

資料來源不可靠時，寧可說讀不到

用量端點有速率限制，也可能因 token 過期而失敗。與其根據對話紀錄自行推算用量，不如分層取用官方資料：先查端點、失敗再讀桌面版快取，兩者都沒有就明確顯示讀不到。

取捨

偶爾會看到「讀不到」，但看到的數字一定是官方的。

Windows 系統匣（pystray）
├─ 置頂卡片 / 工作列迷你橫條（Tkinter）
└─ 圖示繪製：Pillow，6 種樣式
資料來源（依序嘗試）：
├─ 官方用量端點（約每 2 分鐘）
├─ Claude 桌面版本機快取
└─ 都失敗 → 顯示讀不到
